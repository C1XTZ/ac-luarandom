# xtzUI

[![](https://img.shields.io/badge/Download%20Latest-gray?style=for-the-badge&logo=Github)](https://danielcregg.github.io/github-folder-downloader/?url=https://github.com/C1XTZ/ac-luarandom/tree/main/apps/xtzUI)

A stripped down version of the [RennsportHUD](https://github.com/C1XTZ/ac-rennsporthud) Essentials element with a different font and some other minor changes.

I have the following custom keybinds implemented for my wheel (TM TMX):

- Button A will flash the highbeams.
- Button X will teleport back to pits and then to my prefered TP location (C1 Outer - Bayshore Access)

# Mesh Mover

[![](https://img.shields.io/badge/Download%20Latest-gray?style=for-the-badge&logo=Github)](https://danielcregg.github.io/github-folder-downloader/?url=https://github.com/C1XTZ/ac-luarandom/tree/main/apps/meshmover)

Quick and dirty way to move a mesh around.
Has a 2nd tab that inserts the LIDL Fumo and moves it around without having to restart the game. LIDL Fumo not included in the repo.
Used to generate skin extention configurations for [SRP Fast Car Skin Pack](https://www.overtake.gg/downloads/srp-fast-car-skin-pack.77452/)
